# QBE Insurance

> QBE Insurance Group Limited is a Sydney-headquartered, ASX-listed global general insurance and
> reinsurance group operating across Australia Pacific, North America and International divisions,
> including a Lloyd's of London syndicate. QBE distributes through brokers and agents rather than
> direct to consumers, and its API posture follows that model: real developer portals, real reference
> documentation, but partner-gated access with no self-serve signup anywhere.

Generated by API Evangelist on 2026-07-25 from https://github.com/api-evangelist/qbe. QBE publishes no
llms.txt of its own — https://connect.api-au.qbe.com/llms.txt, https://gateway.api-au.qbe.com/llms.txt
and https://partnerportal-api.qbena.com/llms.txt all return HTTP 404.

## What an agent can and cannot do here

- You CANNOT self-serve. Both QBE Australia API products are `subscriptionRequired: true` and
  `approvalRequired: true`; the broker API additionally requires an `X-Partner-Id` drawn from a fixed
  enumeration (AUSTBROKERS, MARSH, PSC). QBE North America emails credentials after business approval.
- You CAN read the full Australian reference anonymously — catalogue, operations, parameters,
  request/response representations, examples and the 258-schema components document are all served
  without a login by the Azure APIM developer-portal data endpoints.
- There is no claims / FNOL surface, no events, no webhooks, no GraphQL, no gRPC and no MCP server.
- There is no ACORD anywhere. QBE uses its own canonical policy model.

## APIs

- [QBE Australia ANZO Digital Brokers Experience API](https://connect.api-au.qbe.com/apis): the broker
  commercial policy lifecycle — create/modify/abandon/refer a quote, bind a quote into a policy, then
  endorse, renew, cancel, abandon or refer the policy, plus quote and policy document upload and a
  health check. 15 operations. Base URL https://gateway.api-au.qbe.com/x-digital-brokers-qbe-anzo/api
- [QBE Australia CTP Switch Service](https://connect.api-au.qbe.com/apis): two operations supporting
  the compulsory third party motor insurance switching flow. Base URL
  https://gateway.api-au.qbe.com/ctp-service
- [QBE North America API Product Hub](https://partnerportal-api.qbena.com/apis/catalog): seven named
  partner API products for Renters and Homeowners — Quote API (Renters), Quote API (Homeowners),
  Bind API, Master Liability API, Property Inquiry API, Zip Code Validate API, and Reconciliation and
  Cancellation. Endpoints and specs are not published anonymously.

## Calling convention

Every ANZO Digital Brokers business call needs: `Ocp-Apim-Subscription-Key` (approved APIM
subscription), `X-ClientID`, `X-ClientSecret`, `X-Partner-Id`, and `X-TrackingID`. A two-step lifecycle
transaction (endorse / cancel / renew, then bind / abandon / refer) replays the same `x-master-ref-id`
plus the matching `x-*-policy-transaction` value (ENDORSEMENT | CANCEL | RENEWAL). Errors return
`{"errors":[{"code","message","details"}]}` — not RFC 9457. There is no idempotency key.
